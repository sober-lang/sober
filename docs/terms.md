# 用語表（日本語の文書）

日本語が正の文書（README.ja.md・docs/guide・docs/spec・docs/design-notes・設計文書）で使う語を、裁定ごとに記録する。

原則: **その分野で定着した語を使う**。プログラミング言語とコンパイラの分野で、日本語で書く人がふだん使う呼び名を選び、英語の直訳やこのプロジェクトの中だけの言い回しは文書に出さない。識別子・コード・コマンド・ファイル名・画面の文言はこの表の対象外（そのまま書く）。
