# 設計ノート — なぜ X でなく Y か

Sober の細かい設計判断を、利用者がよく抱く問いの形で集めたものです。各項目は問い・答え・棄てた案・関連の順に書いています。主要な判断の柱は [DESIGN.md](../../DESIGN.ja.md) に、正確な定義は [言語仕様](../language.md) にあります。

| ノート | README の柱 | 主な問い |
|---|---|---|
| [minimal.md](minimal.md) | ミニマル | なぜ依存ゼロ・なぜ Zig から完全ブートストラップ・なぜ世界を閉じる・検証の網とは |
| [fast.md](fast.md) | 高速 | なぜ LLVM を使わない・なぜ素直に書いて速いと言える・ベンチの規律・決定的な並列 |
| [safe.md](safe.md) | 安全 | GC も借用検査も無しでなぜ安全・データ競合自由・エラーの取りこぼし・panic の範囲 |
| [plain.md](plain.md) | 平凡 | なぜメソッド・interface・マクロが無い・なぜ多値を変数に入れない・なぜ T? |

項目は設計の記録（docs の各節の「棄てた案」）から、利用者の問いになるものを選んで書き直しています。
