# 設計ノート — なぜXでなくYか

Soberの細かい設計判断を、利用者がよく抱く問いの形で集めたものです。各項目は問い・答え・棄てた案・関連の順に書いています。主要な判断の柱は [DESIGN.md](../../DESIGN.ja.md) に、正確な定義は [言語仕様](../spec/README.ja.md) にあります。

| ノート | 柱 | 主な問い |
|---|---|---|
| [minimal.md](minimal.md) | ミニマル | なぜ依存ゼロ・なぜZigから完全ブートストラップ・なぜ世界を閉じる・検証の体系とは |
| [fast.md](fast.md) | 高速 | なぜLLVMを使わない・なぜ素直に書いて速いと言える・ベンチの規律・決定的な並列 |
| [safe.md](safe.md) | 安全 | GCも借用検査も無しでなぜ安全・なぜデータ競合が起きない・エラーの取りこぼし・panicの範囲 |
| [plain.md](plain.md) | 平凡 | なぜメソッド・interface・マクロが無い・なぜ多値を変数に入れない・なぜT? |
| [not-in-sober.md](not-in-sober.md) | — | 意図して入れないもの（理由と代わりの一覧） |
| [related-work.md](related-work.md) | — | 先行研究 — 機構ごとに何を継ぎ、何を変えたか |

項目は設計の記録（docsの各節の「棄てた案」）から、利用者の問いになるものを選んで書き直しています。
