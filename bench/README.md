1 つの論理 CPU に固定し、Sober → Go の交互で 5 回測った。cycles と wall は最小をとり、命令数は決定的な値。出力は毎回 Sober ≡ Go で、fasta / revcomp / k-nucleotide / n-body / spectral-norm / mandelbrot は benchmarks game の公式の期待出力とも一致する。再現: `scripts/bench.sh -n 5`（実行ファイルと入力を置く）→ `bench/seqperf.sh -n 5`。

- 物差しは cycles。命令数は 7 題材で Sober の方が多いが、cycles では互角かそれ以下に収まる（1 命令あたりの仕事が軽い — 依存の鎖・メモリ待ちで律速する形）。wall は同居の負荷で揺れるので参考
- 前回（6.5 第 1・2 便後の 2026-10-08 計測）からの動き: 配置の便（関数の先頭を 64 B に整列・小さい最内ループに 64 B の線を跨がせない詰め物 — 詰め物は実行されない場所に置く）。命令は 9 題材とも不変で、cycles は fasta −5%・k-nucleotide −0.4%・fannkuch −0.3%・1BRC ±0 と揺れの幅に収まる。配置の当たり外れの大きい粒度の葉（並列の対照）では、8 配置の最悪 −41〜43%。fannkuch の予測ミスの二峰は、関数の 64 B 整列で「ほかの関数の変化」からは切り離した（関数自身の変化からは守られない）
- その前（並列 1.0× アタック便後の 2026-10-08 計測）からの動き: -O2 水準レーン 6.5 第 1・2 便（ループの回転・比較の flags 読み・lea / 2 番地形の合成・mut 排他を使った hdr の資格拡張・cvtsi2sd の偽依存切り・x·2.0 → x+x）で fasta −15%・revcomp −13%・k-nucleotide −5%・1BRC −3%・spectral-norm −2%（cycles）。spectral-norm は反転（1.01× → 0.99×）。fannkuch は命令 −9% でも cycles +1.9%（予測ミスが配置で二峰 148 / 161 M）
- RSS の 0.4 MB は静的リンクの最小の常駐分。bench.sh の表の RSS（2 MB）は taskset 由来の床を含む（[par/README.md](par/README.md) の環境の節）

## 4. この数字が約束つきであること

- UTF-8: 文字列は常に有効な UTF-8。1BRC は入力の全量（136 MB）を 1 回検査し、切り出しは定理で検査なしにしている — 「検査しない」で速いのではない
- 境界コピー: 関数・task・チャネルの境界を渡る値は写す意味論（別名による破壊が構造的にない）。速さは宛先構築など観測できない最適化で取り返している
- 決定性: 同じ版・同じ入力なら出力は同じバイト。並列の数字も W1 ≡ W8 のバイト一致の網（selfpar・schedfuzz・seqpar・parbudget）の下で測った
- GC なし: RSS は生きているデータの量に追従する（GC のヘッドルームがない）。Go の RSS には GOGC=100 のヘッドルームが含まれる

## 5. 負けている軸（帰属つき）

- fannkuch 1.03×（cycles）: 唯一の負け。命令は 1.27× → 1.16× まで縮めたのに cycles が戻った — 予測ミスが配置で二峰（148 / 161 M）に割れるため（同一機械語で配置だけが決める族）。配置の便で「ほかの関数の変化」による峰の行き来は止めた（関数の先頭 64 B — 今は良い峰の側）が、予測器の索引の衝突そのものは規則にできていない。mandelbrot 1.00× は互角圏
- reverse-complement の RSS 1.74×: 出力を全部溜めてから 1 回で書く素直形のため。io の書きバッファ（ストリーム形）のピン待ち
- 命令数そのもの（n-body 2.23×・k-nucleotide 1.72×）: cycles では勝っているが、命令の質の伸び代として残っている
- イディオムギャップ（下の表）: 交互の append は回避形の 3 倍の命令（崖は消えて定数倍だけ残った形）。シリアライザは入れ子が深いほど合成の写しが効く（d6 で +33%）
- Go の温のビルドが 2.5 倍速い（題材 1 本で 0.09 vs 0.23 s）
