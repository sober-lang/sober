# 置き場所の表（検証の増分化 — .pair設計 design-gateincr-2）: 保証ごとに確かめる場所を1か所に決める。場所はチェックレベル（gates.sh --level N — 数字が大きいほど網が細かい）と一対一:
#   レベル1 branch（札なし）  = 変更の検証: 枝の変更だけで値が決まる保証。枝の取り込みの前の契約
#   レベル2 train（@place train） = 合成の検証: 合成で初めて値が決まる保証（出力の照合・上限値）。push前。レベル1の結果は scripts/carry.ts の条件で持ち越す
#   レベル3 nightly（@place nightly） = 包括の網: 全部を冷で・実行時間の線の FAIL。1日1回
#   レベル4 release = リリース: レベル3 + タグ release のゲート
# 2か所目で確かめるのは @recheck の行だけ（理由のコメントは必須）。@regen = 取り直しの道具（regen.sh・上限値の取り直し）が書くパス（列車の上で merge 以外に変えてよいパス）
@place train: astjson corejson irtext lltext loaderjson effectsdump secretdump ctcheck stdref clidoc docsync stages selfpar framestat ringinst reqinst lparcfg memcheck profcov   # 合成で初めて値が決まる（出力の照合・上限値）

@recheck nightly: all   # branch の結果の持ち越し（train）は合成の相互作用を見ない。外れを1日以内に捕まえる
